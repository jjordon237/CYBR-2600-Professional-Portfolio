## Commonwealth Bank — In Progress

I am working through hands-on, authorized web application security labs associated with my Commonwealth Bank virtual simulation work. These exercises emphasize understanding application behavior, recognizing security weaknesses, interpreting HTTP interactions, and documenting findings in a controlled training environment.

### Hands-on topics currently being studied

- **SQL injection:** Learning how applications interact with relational databases and why unsafe handling of user-supplied input can create security vulnerabilities.
- **NoSQL injection:** Exploring how injection risks can arise in applications that use nonrelational databases and different query structures.
- **OAuth and authorization:** Currently working through OAuth concepts, authentication and delegated-authorization flows, and the security considerations of access tokens and application permissions.
- **Web application testing methodology:** Practicing systematic observation, request/response analysis, evidence collection, and clear technical documentation in authorized labs.
- **Additional web-security topics:** Continuing to explore other vulnerability categories as assigned; specific topics and outcomes will be recorded when completed.

**Tools and environment:** Hands-on web-security training labs and web request analysis tools used within the authorized educational scope.

**Status:** In progress. These subjects are areas of active study, not claims of mastery, completed lab counts, or professional penetration-testing credentials.
