2. **Identify Target Roles** — Review cybersecurity and IT positions that align with my interests  
3. **Analyze Job Requirements** — Identify recurring skills, tools, credentials, and responsibilities  
4. **Connect Evidence** — Match portfolio projects to relevant employer requirements  
5. **Strengthen Accomplishments** — Use clear, results-oriented descriptions  
6. **Review Presentation** — Improve readability, organization, consistency, and professionalism  
7. **Create Tailored Versions** — Adapt the résumé and cover letter for specific opportunities
