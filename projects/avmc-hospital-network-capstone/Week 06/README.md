# AVMC Capstone - Week 6 Portfolio Package

Week 6 documents the point where the AVMC Packet Tracer network became a functioning client/server environment rather than only a segmented routed infrastructure.

## Included

- `WEEK_6_PROGRESS.md` - GitHub-friendly technical progress report.
- `AVMC_Capstone_Week6_Progress_Report_James_Jordon.docx` - formatted portfolio/report version.
- `images/` - reduced evidence set with twelve non-duplicate screenshots.
- `images/README.md` - image index and upload guidance.

## Add before final GitHub upload

Place the saved Packet Tracer checkpoint in this folder as:

`AVMC_Capstone_James Jordon_v3.0.pkt`

The `.pkt` file is created in Cisco Packet Tracer on the student's computer and is not generated by this documentation package.

## Week 6 checkpoint summary

The checkpoint includes bidirectional CORE/EDGE routing, a live VLAN 50 server segment, centralized DHCP/DNS, DHCP relay, working EHR name/application access, validated ADMIN/CLINICAL/IMG-LAB endpoints, and the first wireless MED-IOT endpoint successfully tested with a Packet Tracer Simple PDU.
