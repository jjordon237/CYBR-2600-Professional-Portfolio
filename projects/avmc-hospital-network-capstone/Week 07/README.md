# AVMC Capstone - Week 7 Portfolio Package

**Course:** NET-2650 Capstone Planning and Implementation

## Week 7 Focus

Week 7 expanded the AVMC Packet Tracer environment in two major areas: **Facilities / Building Management Systems (BMS)** and **Guest Wireless Access**. The work added physical-security and facilities IoT endpoints, completed representative wireless camera integration, expanded the Facilities DHCP pool, and built a realistic guest waiting-room network with several BYOD device types.

This week intentionally preserved broad baseline reachability before security hardening. That provides a measurable **before state** for Week 8 ACL, management, device-hardening, and segmentation tests.

## Security / Publication Note

Wireless pre-shared keys, IoT registration passwords, and other credentials are intentionally **not documented** in this public-facing package. Screenshots that visibly exposed credentials were excluded from the curated image set.

## Next Phase

Week 8 is planned as the final hardening and validation phase, including guest isolation, restricted IoT access, management-plane hardening, additional Layer 2 protections where supported by Packet Tracer, public/internal AVMC web services, and final allow/deny testing.
