# AVMC Week 4 Evidence Images

This folder contains screenshots used as technical evidence for the **Appalachian Valley Medical Center (AVMC) Packet Tracer Capstone** Week 4 progress report.

The images document both successful configuration milestones and troubleshooting performed during the build, including routed core-to-edge connectivity, VLAN creation, 802.1Q trunk configuration, native VLAN mismatch errors, Spanning Tree Protocol recovery, and final verification output.

## Evidence Included

Screenshots in this folder may include:

- Initial topology and infrastructure placement
- CORE-SW1 to EDGE-RTR routed link configuration
- Successful ICMP connectivity verification
- VLAN creation on CORE-SW1
- Server VLAN assignment
- CLIN-SW1 trunk configuration and verification
- OPS-SW1 trunk configuration and verification
- Native VLAN mismatch and STP troubleshooting
- Final `show interfaces trunk` verification

These screenshots support the accompanying [`WEEK_4_PROGRESS.md`](../WEEK_4_PROGRESS.md) project log and are retained to show the actual configuration and troubleshooting process rather than only the final working state.
